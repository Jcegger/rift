# What goes on the Kobo Libra Colour. Built by scripts/build-kobo (locally, and by the
# kobo-sheets GitHub Action on every push that touches a source), published on the
# `kobo-sheets` branch. The Plex server fetches that branch, converts the PDFs for the
# Kobo and puts each collection on the device as a Kobo collection, over Wi-Fi.
# (egger-theater: plans/kobo-komga.md "Docs".)
#
#   <collection>   <source>   [title="..."]   [write]
#
# The title is what the Kobo shows; lines keep their order inside a collection.
# Two routes to the Kobo, both over Wi-Fi:
#   Google Drive  every sheet as a PDF named "<collection> - <title>.pdf" in the Drive folder
#                 "Rakuten Kobo" (the Kobo downloads it on Sync, anywhere). The Action uploads it
#                 when the GitHub secret RCLONE_CONF is set. Reference sheets are replaced when they
#                 change; `write` sheets only go up if missing, so a copy you wrote on is never replaced.
#   Komga         reference sheets also as Kobo books in the collection, via the Plex server (at home).
# source  <path>.md          built at the Kobo's page size with guides/eink-kobo.css
#         journal:<sheet>    from scripts/build-journal --kobo: card (matchup card), match-night,
#                            trouble-list, review
# write   a sheet you write on with the stylus: PDF only (Kobo saves pen ink inside a PDF).
