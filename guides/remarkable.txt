# What scripts/sync-remarkable puts on the reMarkable, one line per document:
#
#   <cloud folder>  <mode>  <source>
#
# mode   update  rebuild and replace the PDF's content on every sync, keeping your
#                highlights and handwriting (rmapi put --content-only)
#        once    upload only if it isn't there yet. For sheets you write on: replacing
#                one would misalign your handwriting with a new layout
# source journal:<name>  a PDF from scripts/build-journal
#        <guide-name>    guides/<guide-name>.md, built with scripts/build-guide --pdf
#        <path>.md       any Markdown path (docs/, notes/), built the same way
#
# Reading copies stay current; to drop one from the tablet, delete its line here and
# remove it on the device.
